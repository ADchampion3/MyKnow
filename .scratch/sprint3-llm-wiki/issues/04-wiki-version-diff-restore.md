# 04 — Wiki 编辑、diff、恢复与版本冲突

**What to build:** 用户可以安全编辑 Wiki 页面，查看版本差异，并将旧版本恢复为新的当前版本；旧页面内容不会被覆盖。

**Blocked by:** 03 — 类型化 Wiki 页面与版本化模板

**Status:** ready-for-agent

- [ ] 同一页面两次编辑生成不可变的新版本。
- [ ] diff 明确显示新增和删除内容。
- [ ] 恢复旧版本会生成新版本，所有历史版本仍可查看。
- [ ] 保存请求携带基础版本身份，旧版本保存返回 `WIKI_VERSION_CONFLICT`。
- [ ] 页面元数据修改不会意外修改正文版本。
- [ ] 编辑器、预览、版本列表、diff 和恢复操作均可从 Wiki 工作台完成。
- [ ] focused check 覆盖并发冲突、两次编辑和恢复链。
