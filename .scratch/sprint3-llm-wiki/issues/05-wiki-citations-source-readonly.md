# 05 — Wiki block 引用与只读原始资料

**What to build:** 用户可以把 Wiki block 引用到具体资料版本和原文定位，并从引用跳转到只读源内容；一个页面可以综合多个资料来源。

**Blocked by:** 04 — Wiki 编辑、diff、恢复与版本冲突

**Status:** ready-for-agent

- [ ] 引用绑定具体资源版本、页面 block 和 locator，不绑定会移动的当前版本指针。
- [ ] 一个 Wiki 页面可以保存来自多个资料版本的引用。
- [ ] 点击引用可以打开对应资料版本和原文定位。
- [ ] 无法解析的目标或 locator 明确显示为 `broken`。
- [ ] 页面引用、引用列表和资料版本信息在刷新后保持一致。
- [ ] UI 和 API 都拒绝修改或删除原始资料。
- [ ] focused check 覆盖多来源引用、版本定位、失效引用和源层不可变性。
